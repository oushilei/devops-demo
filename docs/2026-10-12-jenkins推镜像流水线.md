# Jenkins 凭据管理 + 推送镜像到私有仓库（2026-10-12）

## 目标
把 Day2 的流水线从「构建完就结束」扩展为「构建 → 推送到 registry」。

## 凭据创建
Jenkins → 系统管理 → 凭据 → 全局凭据 → 添加凭据

| 字段 | 值 |
|---|---|
| 类型 | Username with password |
| 范围 | 全局 |
| 用户名 | admin |
| 密码 | admin123（registry:2 默认不校验，流程与 Harbor 一致） |
| ID | registry-cred |

ID 是流水线引用的唯一标识，必须手填。不填则 Jenkins 生成 UUID，
无法在流水线中引用。

## Jenkinsfile 关键片段

    environment {
        REGISTRY      = '192.168.2.150:5000'
        IMAGE_NAME    = 'devops-demo'
        REGISTRY_CRED = credentials('registry-cred')
    }

    stage('推镜像') {
        steps {
            sh '''
                echo "$REGISTRY_CRED_PSW" | docker login $REGISTRY -u "$REGISTRY_CRED_USR" --password-stdin
                docker tag ${IMAGE_NAME}:v1 $REGISTRY/${IMAGE_NAME}:v1
                docker push $REGISTRY/${IMAGE_NAME}:v1
            '''
        }
    }

    post {
        always { sh 'docker logout $REGISTRY || true' }
    }

## 三个关键设计点

### 1. credentials() 生成两个变量

    REGISTRY_CRED = credentials('registry-cred')
    → REGISTRY_CRED_USR
    → REGISTRY_CRED_PSW

后缀是 _USR / _PSW，不是 _USER / _PASS。

### 2. 为什么用 --password-stdin

docker login -p 明文密码 会把密码写进 ~/.bash_history 和进程列表。
用管道传标准输入，密码不出现在命令历史里。

### 3. 为什么 post 里要 logout

docker login 把凭据写进 ~/.docker/config.json，是 base64 编码而非加密。
构建结束应清理，避免被后续构建或他人复用。|| true 是为了没登录时
logout 返回非 0 导致 post 失败。

## 日志里的两个警告

### WARNING: password stored unencrypted

docker login 的凭据是 base64 编码（非加密）存在 ~/.docker/config.json。
生产环境应配置 credential helper（docker-credential-pass 等），
把凭据存进系统密钥环。

### DEPRECATED: The legacy builder is deprecated

Docker 正在淘汰老构建器，新的是 BuildKit（配合 buildx）。
BuildKit 优势：并行构建多阶段、更优缓存、支持多架构镜像、
构建密钥（--secret）不落进镜像层。

## 面试话术

Q：Jenkins 里怎么管理密码，怎么保证不泄露？
A：三层机制。
   存储层：密码存 Jenkins Credentials，加密保存在 master 端 credentials.xml，
           流水线通过 credentialsId 引用，代码里无明文。
   注入层：environment { X = credentials('id') } 或 withCredentials 绑定，
           credentials() 自动生成 _USR 和 _PSW 两个变量。
   打码层：Jenkins 把凭据值登记进掩码列表，日志中匹配到的字符串替换为 ****。
   补充：传输用 --password-stdin 避免进 shell 历史；用完 post { always }
        里 docker logout 清理。
